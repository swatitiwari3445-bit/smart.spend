# 💰 SmartSpend – Personal Expense Tracker & Data Analytics Dashboard

## 📌 About the Project

SmartSpend is a personal expense tracking and data analytics web application designed to help users manage their daily expenses, monitor their monthly budget, and understand their spending habits.

It provides interactive charts and useful insights to make personal financial management easier.

## ✨ Features

- Add and manage daily expenses.
- Delete expenses when required.
- Categorize expenses into Food, Travel, Shopping, Education, Bills and more.
- Set and monitor monthly budgets.
- Track remaining budget.
- Interactive Pie Chart for category-wise spending.
- Monthly Bar Chart for spending comparison.
- View complete expense history.
- Filter expenses by month.
- Download expense reports in PDF format.
- Export expense data as CSV.
- Save data using Browser Local Storage.
- Responsive design for desktop and mobile.

## 🛠️ Technologies Used

- HTML5 – Website Structure
- CSS3 – Styling and Responsive Design
- JavaScript – Functionality and Data Analysis
- Chart.js – Interactive Charts
- jsPDF – PDF Report Generation
- Local Storage – Data Storage

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Add your expenses.
5. Set your monthly budget.
6. Explore charts and download reports.

## 📊 Dashboard Analytics

SmartSpend provides:

- Category-wise expense analysis.
- Monthly spending comparison.
- Budget utilization tracking.
- Highest spending category identification.

## 🎯 Project Objective

The main objective of SmartSpend is to make expense management simple and accessible.

It helps users understand where their money goes, control unnecessary spending, and make better financial decisions through data visualization.
